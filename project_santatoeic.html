Introduction

Santa Toeic is a service that uses adaptive AI to recommend questions to help test takers achieve their TOEIC target score. We designed and implemented a timer feature to help test takers solve real-world problems, as well as a chat feature that allows them to ask questions to experts if they encounter a question they don't understand.

Santa Toeic은 토익 목표 점수를 달성할 수 있도록 AI가 문제를 추천해 주는 서비스입니다. 토익 문제를 풀 때 타이머를 제공하여 수험생들이 실전에서 문제 푸는 데 도움이 될 수 있는 기능과 문제를 풀다가 모르는 문제 발견 시 전문가에게 질문할 수 있는 채팅 기능 화면을 설계하고 디자인했습니다.
