Introduction

Imgplay is a service that allows you to create animated GIFs on your mobile device. Starting with the task of improving the iPad main screen, which provided a similar app design environment, we analyzed Firebase analytics and user needs to add new features and improve the app.

Imgplay는 모바일로 움짤(GIF)을 만들 수 있는 서비스입니다. 앱 디자인 환경 그대로를 제공하고 있었던 iPad 메인 화면 개선 과제를 시작으로 Firebase 분석과 사용자 니즈를 분석하여 앱 내 신규 기능 추가 및 개선을 진행했습니다.

Key Implementations:

UX/UI Design:
UX/UI design and resource creation, including mosaics, logos, custom sizes for finished products, and frames.

Resources required for UI:
Frames, documents and videos announcing new features within the app upon update, and event icons.

Data Driven:
Optimized regional text style and contents using Firebase analytics.

UX/UI 디자인 :
텍스트, 스티커, 이펙트, 모자이크, 음악, 크롭 기능

리소스 제작:
프레임, 업데이트 시 앱내 새로운 기능 안내 문서 및 영상, 이벤트 아이콘 등 리소스 제작

데이터 활용:
Firebase 데이터를 활용한 국가별 텍스트 스타일 및 콘텐츠 최적화
